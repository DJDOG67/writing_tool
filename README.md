# 여백

순수문학을 쓰는 사람을 위한 최소한의 집필 도구. 서식도, 자동완성도, 맞춤법 밑줄도 없습니다.

## 남긴 기능

- **쓰기**: 가운데 한 단의 본문. 타자를 치기 시작하면 상단 도구가 사라지고, 마우스를 움직이면 다시 나타납니다.
- **분량**: 공백 포함 글자 수와 200자 원고지 매수. 글자 수 위에 마우스를 올리면 공백 제외 글자 수도 보입니다.
- **판 저장**: 초고, 1차 퇴고처럼 원하는 시점의 원고를 이름 붙여 남깁니다(`Ctrl/⌘ + S`). 기록에서 열어 보고 되돌릴 수 있고, 되돌리기 전 원고는 따로 남겨 둡니다.
- **원고 목록**: 여러 작품을 오가며 씁니다.
- **내보내기**: 지금 원고를 `.txt`로 받습니다.
- **백업**: 모든 원고와 판 기록을 `.json` 한 파일로 받고, 다시 불러옵니다.

## 일부러 뺀 것

굵게·기울임 같은 서식, 글꼴 선택, AI 기능, 맞춤법 검사, 클라우드 동기화, 계정.

## 저장 방식

원고는 브라우저의 IndexedDB에 저장됩니다. 다른 브라우저나 기기로는 자동으로 넘어가지 않으니 「원고 → 전체 백업 받기」로 가끔 백업 파일을 받아 두세요. 브라우저 데이터를 지우면 원고도 사라집니다.

## 원고지 매수 계산

200자 원고지(20칸 × 10줄) 기준의 근사치입니다. 문단마다 새 줄에서 시작하고 첫 칸은 들여쓰기로 비웁니다. 빈 줄은 세지 않고, 문장부호 배치 규칙은 반영하지 않습니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열거나, 저장소 설정에서 GitHub Pages(Branch: `main`, 폴더: `/root`)를 켜면 링크로 쓸 수 있습니다.
